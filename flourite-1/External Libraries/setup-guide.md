# External Libraries Setup Guide

### SFML
- Download `SFML 3.1.0` `Visual C++ 17 (2022)` `x64` file(ZIP file): https://www.sfml-dev.org/download/sfml/3.1.0/
- Create directory `SFML` in this directory.(`External Libraries\SFML\`)
- Extract files to `SFML`.
	- Directory `include` and `lib` must be in `SFML`.(ex: `External Libraries\SFML\include\`, `External Libraries\SFML\lib\`)
	- Extract the other files in the same path.
